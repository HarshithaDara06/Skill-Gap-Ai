SkillGap AI – Intelligent Resume Analyzer

🚀 An AI-powered resume analysis and career recommendation platform.

📌 Project Overview

SkillGap AI is a web-based application designed to analyze resumes, identify skill gaps, evaluate career compatibility, and help users understand which skills they need to improve for their desired career path.

The project aims to make career preparation more structured through automated resume analysis and personalized learning recommendations.

Project Status: 🚧 Work in Progress

✨ Features

- Resume Upload: Upload resumes in PDF format.
- Resume Analysis: Extract and analyze information from resumes.
- Skill Identification: Identify skills mentioned in the uploaded resume.
- Career Matching: Compare resume skills against selected career requirements.
- Resume Strength Score: Evaluate resume strength based on identified skills.
- Skill Gap Analysis: Highlight missing skills required for the selected career.
- Career Recommendations: Suggest suitable career paths based on skill matching.
- Learning Roadmap: Provide learning guidance to improve missing skills.

Note: Features are being developed and improved. Not all planned functionality may be complete.

▶️ How to Run the Project

1. Clone this repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory:

cd SkillGap-AI

3. Install the required dependencies:

pip install flask PyPDF2 spacy

4. Download the spaCy English language model:

python -m spacy download en_core_web_sm

5. Run the application:

python app.py

6. Open the local URL displayed in your terminal in a web browser.
